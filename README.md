# Vynk

Vynk is a terminal-based platform designed to bring student projects from different colleges and universities into one common place.

It helps students discover existing projects, learn from the work of other students, showcase their own projects, and explore projects that are similar or related to their interests.

---

## Problem Statement

Student projects in technical and higher educational institutions are often scattered across different colleges and universities.

Because there is no common platform for discovering these projects, students may face difficulties in:

- Discovering projects developed by students from other institutions
- Learning from existing student projects
- Finding unique and innovative project ideas
- Identifying projects similar to an idea they want to develop
- Exploring projects related to a particular topic or domain
- Finding opportunities for cross-institution collaboration and knowledge sharing

The problem statement aims to develop an integrated platform where project information from different universities and colleges can be brought together to support peer learning and cross-functional research.

---

## Our Solution

Vynk provides a common project ecosystem where students can discover and showcase projects from different colleges and universities.

Students can browse existing projects, add their own projects, check for similar projects before developing an idea, and discover projects related to a particular topic or domain.

Vynk is being developed as a **terminal/CLI application** to provide a simple and lightweight prototype within the available development time.

---

## Features

### 1. Browse Projects

Students can browse projects available on Vynk.

The feature is intended to allow users to:

- View available projects
- Search for projects
- Select a project
- View complete project details

Project details can include information such as the project description, problem statement, objectives, technology stack, institution, team members, and other project information.

---

### 2. Add Project

Students can showcase their own projects by adding them to Vynk.

The project information will be collected one field at a time.

The planned project information includes:

- Project Title
- Problem Statement
- Summary
- Description
- Objectives
- Tech Stack
- Domain / Category
- University / College
- Department
- Team Members
- GitHub Repository Link
- Deployed Project Link

GitHub and deployed links are optional.

---

### 3. Find Similar Projects

Students can enter their own project idea or description to find existing projects that are similar.

Vynk will compare the entered idea with existing projects and display relevant similar projects along with a **similarity score/percentage**.

The purpose is to help students:

- Check whether a similar project already exists
- Discover existing implementations
- Avoid unintentionally repeating existing ideas
- Get inspiration from previous projects

The similarity score represents how similar the projects are. It does **not** represent or prove plagiarism.

---

### 4. Find Related Projects

Students can enter a broader topic, field, or domain and discover projects related to it.

For example, searching for:

`Artificial Intelligence`

could return projects related to:

- Machine Learning
- Natural Language Processing
- Computer Vision
- Deep Learning
- AI applications

Related-project discovery can use information such as project domains, technologies, keywords, titles, and descriptions.
